# Effa Siddiqui — Portfolio

A single-page portfolio site: hero, about, skills, projects, publication, experience, education, and contact.

## How to put this live on GitHub Pages (free)

1. On GitHub, create a **new repository** named exactly:
   `effasiddiqui.github.io`
   (must match your GitHub username exactly, all lowercase)

2. Upload these files to the repository, keeping the folder structure:
   - `index.html`
   - `images/profile.jpg`

3. Go to the repo's **Settings → Pages**. Under "Build and deployment", set Source to
   **Deploy from a branch**, branch: `main`, folder: `/ (root)`. Save.

4. Wait 1–2 minutes, then your site will be live at:
   `https://effasiddiqui.github.io`

## Editing later
- All content lives inside `index.html` — text, project cards, and links are plain HTML, easy to find and edit.
- The "Blood Bank Management System" card currently links to your GitHub profile (`github.com/EffaSiddiqui`) since it's a group project — if you push the actual project code as its own repo, search for `View on GitHub` in `index.html` and swap that link to the specific repo URL. You can also add a `View on GitHub` link to any of the other four project cards the same way.
- To swap the photo, replace `images/profile.jpg` with a new image of the same filename (or update the `src` in `index.html`).
